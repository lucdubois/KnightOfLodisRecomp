Keys

S stamp · P pencil · E erase · I pick (or Alt+click)
C then drag (or Shift+drag, or right-drag) copy a block of the map · X mirror · G snap · B layer
L stamp writes: both → BG0 only → BG1 only · O override art
Space+drag or scroll to pan · 1–4 zoom · Esc cancel
⌘Z / ⇧⌘Z undo / redo · ⌘S save

BG1 draws over BG0, and its see-through pixels show BG0 below (or the sky where BG0 is empty): paint the ground on BG0 first, then objects with BG1 only.

Only cells where the game drew nothing can be painted; the yellow line is the edge of the game's own art. A save writes map_ext.cfg, which a running game re-reads within half a second.

Override art (O) paints over the game's own tiles too (tinted magenta): the pencil sets a tile on the active layer (right-click: no tile there), a stamp writes as usual, and Erase gives a cell back to the game. An override shows only while the game's tile there is the one it replaced, so the game's own changes (the move range) still show. To lift a BG0 object: stamp a whole copy of it on BG1 only, then pencil the ground or wall behind it on BG0.
