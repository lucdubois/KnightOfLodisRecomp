A small update to 1.0 that makes your save and save states reachable, so you can back them up or move them to another device.

## Updating from 1.0

**Install this APK over the one you have. Do not uninstall 1.0 first:** uninstalling deletes your save and save states. Installed over 1.0, the update keeps your save, your save states, your ROM and your settings.

## What's new

- **Your save and save states are in Android's Files app.** Open **Files**, then the location **Knight of Lodis** in its side menu. You will find:
  - `totkol.sav`: the game's save.
  - `states`: the save states of the Save States page (L3+R3). Each one is three files with the same number: `0007.state` (the state), `0007.png` (its picture) and `0007.txt` (its details).
  - If you play a mod: its own save and its own states folder, named with the mod's code (for example `totkol-1a2b3c4d.sav` and `states-1a2b3c4d`).
- **Back up:** copy these files anywhere you like (Downloads, an SD card, a cloud folder).
- **Restore, or move to another device:** copy the files back into **Knight of Lodis**, in the same place and under the same names. For a save state, copy its three files into `states`; it shows on the Save States page after you restart the game. A file that gets replaced is kept beside the new one as `<name>.bak`.
- Replace `totkol.sav` with the game closed: the save is read when the game starts.

Saves and save states made with 1.0 work in 1.0.1.

## New install

The steps are the same as for 1.0: install the APK, select your own *Tactics Ogre: The Knight of Lodis (USA)* ROM on first launch, and press **Play**. The game is not included.
