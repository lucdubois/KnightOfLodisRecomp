A small update to 1.2: the game now keeps a log you can send with a bug report, including what happened when it crashes. As always, the game is not included: you need your own *Tactics Ogre: The Knight of Lodis (USA)* ROM.

**On Android, install this APK over the one you have. Do not uninstall first:** uninstalling deletes your save and save states. Your save, save states, ROM and settings are kept.

On a computer, replace the old AppImage, app or folder with the new one. Your save, save states and settings are in their own folder and are kept.

## What's new

- **Logs for bug reports.** Each time you play, the game writes `last_run.log` in a `logs` folder, and keeps the one from the time before as `previous_run.log`.
  - On a computer, **Options > Technical > Logs** opens that folder.
  - On Android, open the **Files** app: the game appears there as *Knight of Lodis Recomp*, with a `logs` folder.
- **Crash reports.** If the game crashes, a report of what happened is added to the log, and the next time you start the game it tells you so. When you report a crash, please attach `previous_run.log` (or both files).

The logs hold the game's own messages: no ROM or save data, but they do name the game's files and folders, which on a computer include your user name.

Everything in the 1.2 notes still applies, including its known limits. Saves and save states from 1.0 to 1.2 work in 1.2.1.
