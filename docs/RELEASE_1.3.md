Knight of Lodis Recomp now also plays the Japanese version, *Tactics Ogre Gaiden: The Knight of Lodis*. One download plays both: give it either ROM, or both. As always, the game is not included: you need your own ROM of *Tactics Ogre: The Knight of Lodis (USA)* or *Tactics Ogre Gaiden: The Knight of Lodis (Japan)*.

The downloads are larger than before, because each holds both games.

**On Android, install this APK over the one you have. Do not uninstall first:** uninstalling deletes your save and save states. Your save, save states, ROM and settings are kept.

On a computer, replace the old AppImage, app or folder with the new one. Your save, save states and settings are in their own folder and are kept.

## What's new

- **The Japanese version.** The setup screen takes either game's ROM and tells them apart by itself. With both in place, a button on the setup screen switches between them. From the game, **Options > Enhancement Options > Technical > Game** takes you back to the setup screen.
  - Each version has its own save, save states and mod. Your USA files stay exactly where they were, so nothing needs moving. A save from one version does not carry over to the other.
  - The Japanese game is in Japanese, and so is what the second screen shows from it: the unit sheet, equipment and talents, and the help texts. The enhancement options added by this project stay in English.
  - The 3D battlefield and its lighting work in the Japanese version as in the USA one.
  - Achievements are for the USA version only: RetroAchievements' set is made for it. In the Japanese version the Achievements page says so.

## Fixes

- **The menu with translation mods.** With some translation mods (a Spanish one was reported), the menu did not open and the game stayed paused. The menu now opens, with the game's options in English.

## Known limits

- The Japanese version is new and has been tested less than the USA one: not every enhancement has been checked in it yet. Please report what looks wrong.
- On Android, the Files app and Sync Folder handle the USA version's saves only.

Everything in the 1.2 notes still applies. Saves and save states from 1.0 to 1.2.2 work in 1.3.
